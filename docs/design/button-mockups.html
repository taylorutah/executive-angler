Ten production-ready button styles for the Executive Angler dashboard, drawing from Strava's no-nonsense action language and Salesforce Lightning's hierarchy-first system. Each style is rendered at three sizes with branded colors, typography, and hover states. Pick one (or a pair) as the canonical system; the rest become reference for edge cases.

Recommendation

For your dashboard specifically, I'd ship #01 Strava Solid as the "My Journal" primary, #02 Strava Outline for "Contribute" and "Ideas," #06 Icon Tile in place of the cramped 36×36 icon row, and #07 Compact Stat Pill to replace the inline text stats. That's a coherent four-piece system covering every action surface on the page. The other six stay in the library for forms (03/04), filters (05), photo overlays (08), landing (09), and multi-variant actions (10).
